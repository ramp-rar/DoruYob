# DoruYob

AI-помощник по лекарствам и аптекам для Душанбе. Фото упаковки или текст симптома → объяснение через Gemini на таджикском/русском/английском → список ближайших аптек.

## Локальный запуск

```bash
npm install
cp .env.example .env.local
# вписать в .env.local реальный ключ:
# GEMINI_API_KEY=...   (взять на aistudio.google.com/apikey)
npm run dev
```

Открыть http://localhost:3000 — лендинг, кнопка ведёт на `/app` — рабочий инструмент.

## Структура

```
app/
  page.js            — лендинг
  app/page.js        — сам инструмент (фото/текст → результат → аптеки)
  api/analyze/route.js — бэкенд: вызывает Gemini API, отдаёт результат + список аптек
  layout.js, globals.css
components/           — переиспользуемые UI-блоки
lib/
  pharmacies.json     — 10 реальных аптек Душанбе (название, адрес, телефон, координаты)
  i18n.js              — все тексты интерфейса на 3 языках
  prompts.js           — промпт, который уходит в Gemini
  useLang.js           — хук, запоминающий выбранный язык
```

## Деплой на GitHub + Vercel

1. Создать пустой репозиторий на GitHub (без README/лицензии).
2. В этой папке:
   ```bash
   git add .
   git commit -m "DoruYob MVP"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/doruyob.git
   git push -u origin main
   ```
3. Зайти на vercel.com → **Add New Project** → **Import** этот репозиторий с GitHub.
4. Vercel сам определит Next.js — ничего в настройках сборки менять не нужно.
5. Перед первым деплоем: **Settings → Environment Variables** → добавить
   `GEMINI_API_KEY` = ваш ключ. Без этого шага `/api/analyze` вернёт ошибку 500.
6. Deploy. Готовая ссылка появится за ~1 минуту.

Любой новый `git push` в `main` автоматически передеплоивает проект.

## База данных (опционально, но уже подключена в коде)

Лендинг показывает живой счётчик "N лекарств распознано" — он тянется из Postgres через
`/api/stats`. Без базы приложение работает как обычно, счётчик просто не отображается
(никогда не покажет "0" или ошибку).

Чтобы включить: на vercel.com в проекте → **Storage → Marketplace → Neon** (актуальный
путь; отдельного «Vercel Postgres» больше нет — это теперь встроенная интеграция с Neon).
При подключении через дашборд Vercel сам пропишет `DATABASE_URL` в проект — вручную ничего
копировать не нужно. Таблица `analyses` создаётся автоматически при первом запросе.

## Что добавлено сверх базового MVP

- **Живая камера** прямо в приложении (не открытие галереи) — с graceful fallback на обычный выбор файла, если браузер/устройство не поддерживает камеру
- **Сжатие фото на клиенте** перед отправкой (до 1600px по длинной стороне) — устраняет зависания/таймауты на тяжёлых фото с телефона
- **Голосовой ввод** симптома (Web Speech API) — кнопка появляется только если браузер это поддерживает
- **Озвучка результата** вслух (Web Speech Synthesis)
- **Уточняющие вопросы к Gemini** прямо в карточке результата — второй вызов API с контекстом первого ответа
- **Реальный статус "Открыто/До HH:MM"** у аптек — считается на клиенте из структурированных часов работы (не заглушка)
- **PWA** — устанавливается на домашний экран, иконка, manifest, service worker для базового офлайн-шелла

## Известные ограничения MVP (осознанно, ради времени на хакатоне)

- Список аптек статичный (JSON), без живого API карт — так и задумано, чтобы ничего не сломалось на демо.
- Геолокация используется только для сортировки по расстоянию и не блокирует работу, если пользователь её не разрешил.
- Gemini не должен называть точные дозировки — это заложено прямо в промпте (`lib/prompts.js`) как мера безопасности.
